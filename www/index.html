快速开始

几分钟内完成部署

无需复杂配置，开箱即用

1

安装 VB-Cable

在 Windows PC 上安装 VB-Cable 虚拟声卡。程序会自动检测，未安装时回退到默认麦克风设备。

2

启动 Windows 接收端

运行 udp2mic_x64.exe，点击"启动"按钮。程序会自动放行防火墙、常驻系统托盘。

3

安装 Android 发送端

安装 udp2mic_arm64-v8a.apk，打开 App 后点击 IP 框右侧搜索图标，自动发现局域网 PC。

4

选择输入设备（MIC）

在 Windows 音频设置中将默认输入设备设为"VB-Cable"。微信、Zoom、OBS 等应用会自动通过 VB-Cable 接收手机音频。

自行构建

需要 Rust 1.96+、VS Build Tools 2022、CMake 3.22+

build_windows.bat

需要 JDK 17 (Temurin)、Android SDK 35、NDK 27

技术细节

深入每一行代码的工程决策

音频采集

采样率48kHz 固定采集
编码Opus (CBR/VBR，32~512kbps)
音源模式VOICE_COMMUNICATION / MIC
软件处理无（纯直通，硬件降噪由系统托管）

网络

传输UDP，15B 统一包头
发现端口44043
协议v2 二进制 + 旧版纯文本兼容
鉴权8 字节设备 ID
