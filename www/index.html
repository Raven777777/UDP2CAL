概述

UDP2Mic 将 Android 手机变为高品质无线麦克风，音频经 Opus 编码通过 UDP 实时传输到 Windows 接收端，通过 WASAPI 输出到虚拟声卡（VB-Cable），可供微信、Zoom、OBS、游戏等任意应用使用。

全链路零堆分配 · 生产-消费双协程 · JNI 双重边界守卫

主要特性

📱

Android 发送端

  • 生产-消费双协程，消除 AudioRecord 阻塞饥饿
  • 全链路零堆分配：ShortArrayPool 帧复用 + 乒乓缓冲区
  • 智能 AGC：样点级线性插值平滑，自动上限 100x
  • 动态追踪噪声门
  • Opus CBR/VBR 热调节，5 种采样率自适应协商
  • UDP 广播自动发现局域网内 Windows 接收端
  • 网络无缝热重连，改 IP 不重启录音流
🖥️

Windows 接收端

  • Rust + iced 原生 UI，暗色主题，悬浮窗实时音量
  • 5 独立 Opus 解码器，支持所有采样率无缝切换
  • 相位连续流式重采样，EMA 自适应漂移补偿
  • VB-Cable 自动检测，无虚拟声卡时回退默认设备
  • 局域网广播发现服务，监听 44043 端口
  • 注册表持久化配置：开机自启、窗口位置
  • Windows 防火墙自动放行 · 单实例互斥锁

架构亮点

🔄 双协程流水线

生产者独占 IO 线程采集 AudioRecord，通过 Channel(3) 投递帧数据；消费者串行执行 AGC → 噪声门 → 编码 → 发送，天然背压防堆积。

🧹 全链路零分配

ByteArray + ShortArray 双闭环复用池，除热身期 3 次构造外永久零 GC。JNI encoderEncodeTo 直接 memcpy，乒乓缓冲区防脏数据。

🛡️ JNI 双重边界守卫

静态 1276 字节阈值 + 动态精确守卫，极端 VBR 膨胀下也绝不写穿 Java ByteArray 边界导致 SIGSEGV。

📡 广播自动发现

Windows 端常驻 44043 端口监听，Android 端一键搜索局域网内接收端，零配置即连。
