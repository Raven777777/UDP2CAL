概述

UDP2Mic 将 Android 手机变为高品质无线麦克风。Android 端仅维护一个 isVoiceMode 状态变量，由 Opus 信号类型驱动音源自动切换——语音模式通过 VOICE_COMMUNICATION 享受安卓系统原生硬件降噪，全频模式使用 MIC 裸麦直出。无任何软件降噪、AGC 或音效处理代码。Windows 端采用全局单例音频守护线程 + Channel 无锁通信架构，UI 启停不影响底层音频引擎。音频通过 WASAPI 输出到 VB-Cable 虚拟声卡，可供微信、Zoom、OBS、游戏等任意应用使用。

全链路零堆分配 · 音源自适应切换 · 生产-消费双协程 · 全局单例音频守护线程 · JNI 双重边界守卫

主要特性

📱

Android 发送端

  • 音源自适应切换：仅一个 isVoiceMode 状态变量，语音模式→VOICE_COMMUNICATION（系统硬件降噪），全频模式→MIC（裸麦直出），异常回退 MIC 保底
  • 信号类型变更时消费者循环自动检测，重建 AudioRecord，全程零中断
  • 生产-消费双协程，消除 AudioRecord 阻塞饥饿
  • 全链路零堆分配：ShortArrayPool 帧复用 + 乒乓缓冲区
  • 纯直通无软件处理：PCM 直通→Opus 编码，硬件降噪由安卓系统全权托管
  • Opus CBR/VBR 热调节，FEC=2 允许 CELT+FEC，5 采样率自适应协商
  • UDP 广播自动发现局域网内 Windows 接收端
  • 网络无缝热重连，改 IP 不重启录音流
🖥️

Windows 接收端

  • 全局单例音频守护线程：解码器+音频引擎仅初始化一次，通过 SyncChannel 通信，UI 启停不影响底层，彻底根除内存泄漏
  • Rust + iced 原生 UI，模块化深色卡片布局，动态 VU 色彩表（绿/橙/红专业混音台风格）
  • 5 独立 Opus 解码器，支持所有采样率无缝切换
  • 相位连续流式重采样，EMA 自适应漂移补偿 (±0.2% 区间防变调)
  • VB-Cable 自动检测，无虚拟声卡时回退默认设备
  • 注册表持久化配置：开机自启、窗口位置记忆
  • Windows 防火墙自动放行 · 单实例互斥锁

架构亮点

🔀

音源自适应切换

仅维护 isVoiceMode 一个布尔状态驱动全部音源决策。语音模式使用 VOICE_COMMUNICATION 享受系统原生硬件降噪；全频模式使用 MIC 裸麦直出。创建失败自动回退 MIC 保底通路，APP 端无任何软件降噪代码。

🔄

双协程流水线

生产者独占 IO 线程采集 AudioRecord，通过 Channel(3) 投递帧数据；消费者串行执行参数同步→编码→发送。信号类型变更时自动重建音频源，天然背压防堆积。

🎛️

全局单例音频守护线程

Windows 端解码器+AudioWriter 全程仅初始化一次，通过 SyncChannel<AudioMessage> 接收数据。UI 启停仅发送 Reset 消息清空缓冲区，不解构任何音频资源。

🧹

全链路零分配

ByteArray + ShortArray 双闭环复用池，除热身期 3 次构造外永久零 GC。JNI encoderEncodeTo 直接 memcpy，乒乓缓冲区防脏数据。

🛡️

JNI 双重边界守卫

静态 1276 字节阈值 + 动态精确守卫，极端 VBR 膨胀下也绝不写穿 Java ByteArray 边界导致 SIGSEGV。

📡

广播自动发现

Windows 端常驻 44043 端口监听，Android 端一键搜索局域网内接收端，零配置即连。

🖥️

Iced 现代化 UI

模块化深色卡片布局包装"网络配置"与"数据监测"区域。音频电平条采用动态 VU 色彩策略（绿/橙/红专业混音台风格）。
